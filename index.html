Core Principles

LLMs forget. Software projects don't. We bridge that gap.

External Memory

All state is stored in versioned files, keeping the AI's context window focused on logic rather than history.

Phase-Gated

Work progresses in controlled steps. No phase starts until the previous one is verified and status-logged.

Drift Control

New ideas are captured in `suggest.md` without polluting the current execution thread or roadmap.

Session Independent

Resume projects weeks later. The AI reads the workspace and understands exactly where it left off.

Structured Workspace

XenoSkill creates a standardized environment that forces the AI to follow your SDLC, preventing "AI mess" in large codebases.

  • info/

    Houses theory, architecture, and the roadmap.

  • status/

    Execution tracking and phase-specific logs.

  • .ai/

    Global behavior rules and AI personas.

# Project structure
project/
├── info/ # planning
├── INIT_PROMPT.md
└── roadmap.md
├── status/ # logs
├── status.md
└── phase_1.md
├── .ai/ # config
└── AI_RULES.md
├── src/ # application
└── xenoskill-finalize.sh

"Not an Agent"

XenoSkill doesn't automate development. It defines a system that GitHub Copilot, Claude, or ChatGPT follow. Once done, the finalize script scrubs the "AI scaffolding," leaving only clean code and docs.
